That's a good starting definition, Herman. You've identified two important aspects of encapsulation:

### Final Example: Encapsulation in C#

Consider this example:

```csharp
public class BankAccount
{
    private decimal _balance = 0;

    public decimal GetBalance()
    {
        return _balance;
    }

    public void Deposit(decimal amount)
    {
        if (amount > 0)
        {
            _balance += amount;
        }
    }
}
```

This class demonstrates encapsulation because:

- **`_balance` is private:** Other classes cannot directly change the balance.
- **`GetBalance()` is public:** Other classes can read the balance without modifying it.
- **`Deposit()` is public:** Other classes can add money, but only if the amount is positive.

This protects the account's internal data while providing controlled access through public methods.

Your `Scripture` class follows the same principle by keeping `_words` private and allowing controlled changes through `HideSomeWords()`.
